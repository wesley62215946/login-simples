# Login Simples

Interface de login responsiva construída com React e Vite.

## Executar localmente

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Autenticação

A tela está pronta visualmente, mas o envio do formulário ainda não autentica usuários. Para ativar login, cadastro e recuperação de senha, configure as credenciais de um projeto Supabase e conecte o fluxo de autenticação. Copie `.env.example` para `.env.local` e preencha as variáveis do projeto.
